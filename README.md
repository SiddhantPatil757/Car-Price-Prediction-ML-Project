#  Car Price Prediction System

##  Overview
This project is an end-to-end Machine Learning application that predicts the selling price of a car based on various features such as present price, mileage, fuel type, transmission, and age.

The model is deployed using Flask and includes a simple web interface for user interaction.

---

##  Problem Statement
To build a machine learning model that accurately predicts the price of used cars and helps users make informed buying and selling decisions.

---

##  Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn
- Flask
- HTML

---

##  Machine Learning Approach
1. Data Cleaning and Preprocessing  
2. Feature Engineering (Car Age)  
3. Model Training using Random Forest Regressor  
4. Model Evaluation (R², MAE, MSE, RMSE)  
5. Model Saving using Joblib  

---

##  Features Used
- Present Price (Original showroom price)
- Kms Driven
- Fuel Type
- Seller Type
- Transmission
- Owner
- Car Age
